# Darkace01 Homebrew tap

```bash
brew install --cask darkace01/tap/flightdeck
```

| Cask | App |
| --- | --- |
| `flightdeck` | [Flightdeck](https://github.com/Darkace01/flightdeck): a desktop dashboard for GitHub Actions and pull requests |

The cask is updated automatically when Flightdeck is released.
