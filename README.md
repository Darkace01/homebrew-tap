# Darkace01 Homebrew tap

```bash
brew install --cask darkace01/tap/pushback
```

| Cask | App |
| --- | --- |
| `pushback` | [Pushback](https://github.com/Darkace01/pushback): a desktop dashboard for GitHub Actions and pull requests (formerly Flightdeck) |

The cask is updated automatically when Pushback is released. If you installed the old `flightdeck` cask, `brew upgrade` moves you to `pushback`.
